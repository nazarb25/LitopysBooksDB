# LitopysDB

Локальна база бібліографічних записів із PDF серії [«Літопис книг»](https://ukrbook.net/litopysy.html) Книжкової палати України. Кожен запис зберігається окремо в SQLite разом із номером випуску й сторінкою джерела. Оригінальні PDF зберігаються у `data/pdfs/`.

## Встановлення

Потрібні `uv` та Python 3.14.

```bash
uv sync --extra dev
```

## Завантаження та індексація

```bash
uv run litopysdb sync
```

Команда читає список випусків «Літопису книг» і завантажує лише номери, новіші за останній уже збережений у базі. Перший запуск завантажує весь доступний архів і може тривати довго. Якщо нових номерів немає, команда нічого не завантажує та повідомляє про це. Помилка одного нового PDF не зупиняє інші; невдалий номер буде повторно перевірений при наступному запуску.

Повторити всі відсутні випуски, зокрема старі пропуски, використовуючи вже збережені PDF:

```bash
uv run litopysdb sync --retry-missing --reuse-downloaded
```

Щоб перевірити весь список на змінені PDF, використайте `uv run litopysdb sync --refresh`. Незмінні PDF пропускаються за контрольним відбитком. Звичайний `sync` надалі перевіряє тільки появу нових номерів.

Пробний запуск на одному випуску:

```bash
uv run litopysdb sync --since-year 2026 --limit 1
```

Імпорт власного PDF:

```bash
uv run litopysdb import-file /path/to/L_k_16_2026.pdf --year 2026 --number 16 --url https://ukrbook.net/litopys/Knigki/2026/L_k_16_2026.pdf
```

## Пошук

```bash
uv run litopysdb search --author 'Кінг С.'
uv run litopysdb search --author 'Кінг С.' --limit 500
uv run litopysdb search --text 'Темна вежа' --json
uv run litopysdb search --author 'Кінг' --year 2024
uv run litopysdb search --author 'Кінг' --issue-year 2025 --issue-month 6 --issue-number 11
uv run litopysdb search --translator 'Превіра' --publisher 'КСД'
uv run litopysdb search --original-title 'The pornographer diaries' --print-run-min 1000
uv run litopysdb stats
```

Щоб переглядати результати у браузері:

```bash
uv run litopysdb serve
```

Відкрийте <http://127.0.0.1:8000/>. Пошук за автором і назвою та основні фільтри за роком книги, роком, місяцем і номером випуску «Літопису» показані окремими компактними блоками. Згорнутий блок «Додаткові фільтри» містить видавництво, місце видання, перекладача, редактора, ілюстратора, назву та ISBN оригіналу, ISBN книги, УДК, реєстраційний номер, фізичний опис, відомості про відповідальність і діапазон тиражу. Біля кожного результату вказано джерело: номер, місяць і рік «Літопису». Кнопка «Структуровані дані» розкриває таблицю з окремими полями запису, не перевантажуючи загальний список. Пагінація показує загальну кількість результатів, поточну сторінку, кількість сторінок та компактний набір переходів; на сторінці відображається 50 записів. JSON API повертає `total`, `page` і `pages`; документація доступна за `/docs`. Сервер за замовчуванням слухає лише localhost.

## Дані та обмеження

База — `data/litopys.db`, PDF — `data/pdfs/YYYY/NN.pdf`; обидва місця виключені з Git. Поля запису: назва, визначений автор, рік видання книги, ISBN, повний бібліографічний опис, номер запису та сторінка PDF. Для випуску «Літопису» окремо зберігаються номер, місяць і рік, указані на обкладинці. День випуску в PDF не зазначений, тому пошук за конкретним днем неможливий. Пошук за автором використовує поле автора, а не іменний покажчик, де є також редактори, перекладачі та персоналії. Різні написання імені чи ініціалів інколи потребують окремих запитів. Результати — бібліографічні записи, тому різні видання одного твору можуть показуватися окремо.

Після оновлення наявної бази заповніть місяці з уже завантажених PDF:

```bash
uv run litopysdb backfill-months
uv run litopysdb backfill-details
```

У старих PDF трапляються пропуски чи перестановки номерів і помилкові діапазони на обкладинці. Парсер звіряє кількість записів і зберігає повний опис та сторінку для перевірки. Невдалий імпорт не стирає попередніх даних. Недоступне посилання на сайті неможливо індексувати, доки джерело не відновлено. Підсумок поточного імпорту — у [звіті](docs/import-report.md).
