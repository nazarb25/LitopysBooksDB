LitopysDB

Локальна пошукова база бібліографічних записів із державного покажчика «Літопис книг» Книжкової палати України.

2004–2026основний доступний архів

Швидкий старт

git clone https://github.com/nazarb25/LitopysDB.git
cd LitopysDB
uv sync --extra dev
uv run litopysdb db-download
uv run litopysdb serve

Після запуску пошук доступний за адресою http://127.0.0.1:8000. Є фільтри за автором, назвою, роком і номером випуску, видавництвом, перекладачем, ISBN, УДК та іншими структурованими полями.

Оновлення

uv run litopysdb sync

Команда перевіряє каталог Книжкової палати та завантажує лише нові випуски. Якщо нових випусків немає, база не змінюється.

Джерела й PDF

До snapshot входять бібліографічні записи та посилання на сторінки джерел. PDF не перевидаються і завантажуються безпосередньо з сайту Книжкової палати України.

Джерело: Книжкова палата України — державні бібліографічні покажчики.

LitopysDB — незалежний програмний інструмент. Назви й бібліографічні дані походять із зазначеного першоджерела.
